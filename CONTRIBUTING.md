# Contributing

Bug reports and pull requests are welcome.

1. Describe the change and why it is needed.
2. Keep Python 3.10 compatibility and do not introduce dependencies without discussing them.
3. Run `python -m unittest discover -s tests -v` before submitting a pull request.
4. Do not commit H5P packages (`*.h5p`), private quizzes or third-party H5P libraries.
5. Keep input parsing strict: report ambiguous input rather than silently guessing how to interpret it.

By contributing, you confirm that you have the rights necessary to submit your changes under the repository's licence.
